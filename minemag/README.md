# MineMag — 드론·사족보행로봇 자력탐사 지뢰·불발탄 탐지

SENSYS MagDrone R3(2탐침 플럭스게이트 어레이) 자료로 지뢰·불발탄 같은 근지표 소형 표적을 찾는
전용 프로그램이다. 처리 엔진은 저장소 최상위의 공용 라이브러리 `magcore/`를 DroneMag Studio와
함께 쓰고, 파이프라인·화면·설치본은 따로 둔다 — 자료 모델(탐침 2개 × 3축 벡터 × 트랙)과 처리
단계가 광물탐사와 절반 이상 다르기 때문이다.

처리 흐름은 **방은석·정상원·임신혁(2026), "접경지 건설부지 지뢰 탐지를 위한 사족보행로봇 탑재형
자력탐사시스템 적용성 기초 평가", 대한토목학회논문집 46(4), 377–394**의 2.6절을 그대로 따른다.
그 논문에서 쓴 DroneMagAdv의 처리가 이 프로그램의 모듈이 되었고, 기본값은 논문의 실측치다.
왜 분리했는지와 시험 자료 검토는 `C:\magnetic\Landmine\검토_*.md`.

## 구성

```
minemag/
  backend/
    app/
      io_/magdrone_r3.py          R3 ASC 적재 — 두 탐침·트랙·3축·고도 보존, 파일명 날짜 + ms-since-midnight → 시각
      processing/platform_qc.py   플랫폼 잡음 QC — 조용한 구간 잡음, 두 탐침 상관, 스펙트럼(보행·회전익 주기)
      processing/preprocess.py    논문 2.6.1~2.6.2 — 리샘플링, 적응형 Hampel, 영위상 가우시안 LPF, 경로 편집, 헤딩 보정
      processing/gridding.py      논문 2.6.3 — 장력 최소곡률 격자(0.125 m), 추세 제거, 덮임 공백; 반복 측정 비교(블록 평균)
      processing/peaks.py         논문 2.6.4~2.6.5 — THD/ASA 파생 격자, prominence ≥ K × MAD 피크, 유형 구분
      processing/targets.py       측정별 피킹 → 측정 간 매칭 → 등급 → 쌍극자 깊이·모멘트 → CSV/GeoJSON
      store.py / main.py          프로젝트(메모리), FastAPI
    tests/                        합성자료(정답 기준)와 시험장 실자료 두 트랙
    launcher.py                   포트 8100부터 빈 포트를 골라 띄우고 브라우저를 연다
  frontend/                       Vite + React + Leaflet
```

## 실행

저장소 루트의 `run_minemag.bat`을 더블클릭한다. 가상환경(`backend\venv`, DroneMag Studio와 공유)과
프런트 빌드가 없거나 커밋이 바뀌었으면 설치·빌드를 먼저 하고, 8100번부터 빈 포트를 골라 서버를 띄운 뒤
브라우저를 연다. 코드를 고치고 커밋 없이 바로 보려면 `.last_build_commit_minemag`을 지우고 다시 실행한다.

개발 중 수동 실행:

```bat
cd minemag\backend && python -m pytest tests -q
cd minemag\frontend && npm install && npm run build
cd minemag\backend && python launcher.py
```

개발 중에는 `npm run dev`(5174)가 `/api`를 8100으로 넘긴다.

| 내보내기 | 격자 GRD/GeoTIFF, 표적 CSV/GeoJSON | 2.7 | — |

### 실측(시험장 드론 0.5 m 1회 + 로봇 2회)

- 로봇 배경 잡음 49~57 nT rms, 봉우리 4.1 Hz(0.27 m)·2.15 Hz(0.54 m); 두 탐침 상관 0.68이라 구배로 상쇄되지 않음. 드론 6.8 nT.
- 전처리 뒤 THD 피킹(K = 20): 사각형 안 표적 4개가 세 측정 모두에서 잡혀 A.
- 합성자료: 깊이 0.2~0.6 m의 쌍극자 3개에서 THD 위치 오차 0.2 m 이내, 쌍극자 깊이 0.15 m 이내, 모멘트 40% 이내.
