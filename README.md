# 드론 자력탐사 자료 처리 프로그램

드론으로 취득한 자력탐사 자료를 업로드해 필터링, 측선 판별, 일변화/IGRF 보정, 그리딩, RTP/RTE/AS/1VD 파생 그리드까지 처리하는 웹 애플리케이션입니다.

## 구성

- `backend/` — FastAPI 처리 서버 (필터, 측선 자동판별, 일변화 보정, IGRF, 그리딩, FFT 변환)
- `frontend/` — React + Leaflet 지도 UI (업로드, 파라미터 조정, 지도 표시, 수동 측선 편집, 그리드/파생그리드 표시)

## 기능

1. 드론 자력 취득 파일 로딩 — 여러 비행 파일을 동시에 선택하면 하나로 합쳐 처리 (Date/Time/Lat/Lon/Mag 등 컬럼 자동 인식, GGA 전용 필드 시간축 보간)
2. 일변화(베이스 자력계) 자료 로딩 — 여러 로그 파일 동시 업로드 지원. 두 가지 형식을 자동으로 인식합니다: (1) 헤더 없는 쉼표구분 CSV(한글 오전/오후 12시간제, 행마다 날짜 포함), (2) 공백구분 "시 분 초 X Y Z 총자력" 하루 전체(1초 간격, GPS 시각만 있고 파일 내 날짜 없음) 텍스트 — 이 경우 파일명에 포함된 YYYYMMDD 날짜(예: `cyg202607151s.txt` → 2026-07-15)를 자동으로 읽어옵니다. 마지막 열(스칼라 총자력)은 X/Y/Z로부터 재계산하지 않고 그대로 사용합니다(실제 장비에서 별도 스칼라 센서로 측정한 값이라 X/Y/Z로 계산한 값과 정확히 일치하지 않는 것이 정상입니다).
3. 저주파 통과 필터 (Butterworth, 영위상 filtfilt)
4. 이착륙·터닝구간 등 비측선 자료 자동 판별/제거 (측선 방향 허용오차, 터닝 여분 구간(m) 설정 가능). **IMU 흔들림(스웨이) 검출**(기본 켜짐) — 자이로/가속도 컬럼이 있는 포맷(Geometrics MagArrow 등)에서 센서가 비정상적으로 흔들리거나 회전한 구간을 자동 검출해 함께 제외 (지상 대비 드론 자력탐사 비교 사례에서 측선 줄무늬의 주원인으로 지목된 헤딩 오차/센서 스웨이를 원본 자료 단계에서 직접 처리)
5. 일변화 보정 + IGRF 보정 (자력이상 = TMI - IGRF), 베이스 로거 시계 오프셋 보정 지원. **헤딩효과 캘리브레이션 보정**(기본 켜짐, 나침반 컬럼이 있는 포맷에서만) — 저경사도 구역에서 여러 자세로 짧게 비행한 별도 캘리브레이션 파일을 업로드하면, 센서 자세(헤딩)에 따른 판독 오차를 모델링해 흔들림으로 제외되었을 자료도 보정해 살립니다 (Zhang et al. 2022, *The Leading Edge* — Geometrics MagArrow 개발사 논문 기법). 별도 캘리브레이션 비행이 없으면 **측선 자체의 턴(방향전환) 구간을 자동으로 캘리브레이션 자료로 활용**(기본 켜짐, 제조사 지침의 "턴 구간이 보통 가장 좋은 캘리브레이션 자료" 권고 반영). 교차검증 기반 **캘리브레이션 품질 검증**(PASS/FAIL, 기준값 조정 가능)과 측선-캘리브레이션 헤딩 범위 불일치 경고를 함께 제공
6. 위치별 자력값(TMI/이상) 컬러 지도 표시
7. GUI 지도에서 측선 체크박스 또는 폴리곤/사각형 드래그로 추가 수동 제거 — 반대로 자동 판별이 잘못 제외한(비행 흔들림 등) 구간도 "포함(복원) 모드"로 영역을 그려 되살릴 수 있음, "수동 편집 모두 되돌리기"로 완전 자동 상태로 일괄 복귀
8. TMI 값 hover 표시 및 통계(min/max/mean/std)
9. 그리딩 (verde block-mean + 원본 셀(nearest, 기본/빠름)·선형·큐빅·스플라인 보간 선택 가능, 측선 간격 기반 자동 보간 반경으로 측선 사이 공백 최소화). **측선방향 평활화**(기본 켜짐)로 측선 내 자료 간격(보통 1m 내외)이 측선 사이 간격(보통 수십~수백 m)보다 훨씬 촘촘해서 생기는 측선 방향 줄무늬(코러게이션)를 억제 — 어떤 보간 방법을 쓰든 남아 있던 미세한 주름을 완화
10. RTP / RTE / 1VD / AS 파생 그리드 (Blakely 1995 방식 FFT 필터, 직접 구현)
11. 배경지도 (OSM, Esri 위성, Google 위성) — Leaflet 레이어 컨트롤로 전환
12. 헤딩(비행방향) 오차 보정 — 캘리브레이션(figure-8) 비행이 없을 때, 인접한 반대방향 측선 쌍 중 국지적 변화가 적은("조용한") 지점들을 찾아 방향별 평균 오프셋을 추정하고 측선별로 레벨링
13. 컬러맵 선택 (Viridis/Plasma/Turbo/RdYlBu/RdBu/Spectral/Grayscale/**Geosoft Rainbow**) 및 표시 범위(min/max) 수동 지정 — 특정 구간(예: 1000~2000nT)만 확대해서 색상 대비를 높여 볼 수 있음
14. 대용량 자료(수십만 포인트)에서도 매끄러운 지도 렌더링 — 포인트마다 개별 마커를 만드는 대신 캔버스에 직접 그리는 방식이라 색상/값 필드 등 옵션 변경 시 즉시 재도색됨
15. 그리드/파생그리드 위에도 측선(포인트) 레이어를 겹쳐 표시 가능(토글), 그리드 오버레이 불투명도 슬라이더 조절
16. 지도에 측선 번호 라벨 표시 토글 — 수동 편집 시 어느 측선이 몇 번인지 바로 확인 가능
17. 좌표계가 내장된 GeoTIFF(지질도 등 참조 자료) 업로드해 배경지도 위에 중첩 표시 — 여러 장 추가 가능하며 각각 표시여부/불투명도/쌓임순서(위·아래 이동) 조절
18. **힐쉐이드(음영기복) 표시** — 그리드/파생그리드 값 자체를 지형처럼 간주해 광원 효과를 입히는 Geosoft Oasis Montaj 스타일 표시 옵션(matplotlib `LightSource`). 완만한 값 변화도 입체감 있게 강조되어 미세한 경계·구조가 더 잘 드러남 — 광원 방위각/고도각/강조 정도 조절 가능
19. **그리드/파생그리드 GeoTIFF 내보내기** — 화면에 보이는 색상 PNG가 아니라 실제 값(nT 등)이 담긴 단일 밴드 float32 GeoTIFF로 다운로드해 Oasis Montaj/QGIS/ArcGIS 등 다른 프로그램에서 다시 열람·분석 가능
20. **3차원 자력 역산 (실험적)** — 사전 지질정보 없이 관측 자력이상만으로 지하 자화율(susceptibility) 분포 추정
    - 방법: Li & Oldenburg (1996) 심도가중 Tikhonov 역산 + Portniaguine & Zhdanov (2002) IRLS compact/focusing 재가중 (UBC-GIF MAG3D, SimPEG과 같은 계열의 사실상 표준 기법)
    - 정반응(forward) 계산: Fatiando a Terra의 `choclo` 직육면체 자력장 커널(numba 병렬화, 피어리뷰 검증됨)을 감싼 민감도 행렬 생성
    - 지형: DEM(GeoTIFF) 업로드 가능, 없으면 등고비행(일정 고도) 가정 하에 드론 GPS 타원체고에서 지형 추정 — "활성 셀(active cell)" 방식으로 지형 위 공기층 셀을 역산에서 제외
    - **파라미터 자동 설정**: 격자 크기는 측선 간격 기반, 탐사 심도는 자력이상 그리드의 방사평균 파워스펙트럼 기울기로 이상원 심도를 추정(Spector & Grant 1970)해 자동 산정 — 체크박스 해제 시 수동 지정도 가능. "더 상세한 역산"을 위해 격자를 촘촘히/레이어를 많이 잡을수록 실행 시간이 길어짐(최대 1~2분)을 허용하도록 관측점·활성 셀 상한을 상향
    - 결과 도시: 수평 섹션(깊이별 슬라이더, 지도 위 오버레이), 수직 섹션(자유선을 지도에 그리거나 동서/남북 고정 방향 + 위치 슬라이더로 즉시 조회, 크게 보기 패널), 3차원 이상대 뷰 — 세 가지 도시 모두 SI 값 하한/상한 범위 필터 지원
    - **3차원 이상대 뷰**(Plotly `isosurface`): 지정한 SI 범위(하한/상한)에 속하는 부분만 매끈하고 닫힌 하나의 "덩어리" 표면으로 렌더링 — 실제 역산 셀 크기가 크더라도 표시 직전에 더 촘촘한 격자로 삼중선형(trilinear) 보간해 부드럽게 이어 보이도록 처리(역산 결과 자체는 바뀌지 않음). 박스 상단에는 역산에 사용한 관측 자력이상/TMI 지도를 실제 지형 굴곡을 따라 입혀서(drape) 2D 자료와 3D 역산체의 위치 관계를 한눈에 볼 수 있음(체크박스로 켜고 끌 수 있음) — Oasis Montaj/VOXI류 소프트웨어의 일반적인 3차원 역산 결과 도시 방식을 참고
    - **결과 내보내기/불러오기**: 메쉬+모델 전체를 `.npz`로 내보내 나중에 처음부터 다시 역산을 돌리지 않고 그대로 불러와 단면/3D 뷰를 이어볼 수 있음. 활성 셀만 담은 (x, y, z, 자화율) 포인트클라우드 CSV로도 내보내기 가능해 ParaView/Voxler 등 다른 3차원 도구에서도 열람 가능. 수평 섹션도 GeoTIFF로 내보낼 수 있음
    - 격자 크기가 측선 간격보다 커지면(넓은 조사 영역에서 계산량 상한 때문에 발생 가능) 결과 요약에 경고 문구가 표시됨
21. **전체 프로젝트 저장/불러오기** — 업로드한 원본 자료, 처리 파라미터, 수동 측선 편집 상태, DEM, 역산 결과까지 하나의 `.zip`으로 저장하고 나중에 그대로 불러와 처음부터 다시 처리하지 않고 이어서 작업 가능
22. **스파이크(이상치) 제거** — 필터 전에 이동중앙값(rolling median) + MAD(median absolute deviation) 기반 강건 통계로 울타리·차량 등 순간 잡음을 자동 검출/대체 (창 크기, 탐지 민감도 조절 가능, 제거 개수/비율 표시)
23. **타이라인(교차점) 레벨링 (선택 기능)** — 주 측선과 수직으로 비행한 검교정(타이) 측선이 있을 때만 활성화. 측선과 타이라인이 교차하는 지점에서의 값 차이를 이용해 측선별 레벨링 오차를 추정/보정 (타이라인이 없는 조사에서는 자동으로 비활성 상태 유지)
24. **등고선(등자력선) 오버레이 + 축척바 + 북쪽 화살표** — 그리드/파생그리드 값으로부터 등고선을 계산해 벡터 폴리라인으로 지도 위에 표시(간격 수동 지정 또는 자동 분할), Leaflet 축척 컨트롤과 고정 북쪽 화살표로 지도 판독성 향상
25. **오일러 디컨볼루션 (빠른 심도 추정)** — Euler's homogeneity equation을 그리드의 수평/수직 미분에 적용해 이상체의 대략적 위치·깊이를 빠르게 추정하는 표준 QC 기법. 구조지수(접촉면/암맥/파이프/구형) 선택, 탐색창 크기·깊이 불확실도 허용치 조절 가능, 결과를 깊이별 색상의 지도 마커로 표시 — 3차원 역산보다 훨씬 빠르지만 개략적인 결과
26. **히스토그램 균등화 색상 스트레치** — 기본 선형 스트레치 대신, 값의 실제 분포(순위)에 맞춰 색상을 재분배하는 옵션. 몇몇 극단적인 이상값이 나머지 자료의 색상 대비를 다 잡아먹는 상황을 완화
27. **GPS-자력계 시간 오프셋 보정** — 자력계 내부 필터링/통신 지연으로 위치와 자력값이 실제로 어긋나 있을 때, 알려진 지연시간만큼 위치 트랙을 재보간해 자력 샘플에 다시 매칭
28. **컬러 GeoTIFF 내보내기** — 값 그대로의 GeoTIFF(기존)에 더해, 화면에 보이는 컬러맵/힐쉐이드가 그대로 구워진 RGBA GeoTIFF도 선택적으로 내보내기 가능 (Google Earth 등에서 바로 열람할 때 적합)
29. **작업 단계 안내(진행 표시줄)** — 사이드바 상단에 업로드→처리→그리딩→(선택)고급분석의 진행 상태를 체크마크로 표시
30. **업로드 진행률 표시줄** — 대용량 CSV 업로드 시 실시간 진행률(%) 표시
31. **반응형 레이아웃** — 좁은 화면(태블릿/작은 창)에서는 좌우 패널이 슬라이드오버 형태로 접히고, 지도가 전체 폭을 차지 (넓은 화면에서는 기존과 동일)
32. **전문용어 툴팁** — TMI/IGRF/RTP/RTE/1VD/AS 등 약어에 마우스를 올리면 설명이 표시됨
33. **처리 보고서 생성(Markdown)** — 지금까지 적용된 모든 보정과 그 수치, 측선별 요약, 통계, (실행했다면) 3차원 역산/오일러 디컨볼루션 결과까지 정리한 보고서를 `.md` 파일로 다운로드
34. **프론트엔드 코드 스플리팅** — 3차원 뷰(Plotly, 용량 큰 라이브러리)를 별도 청크로 분리해 처음 페이지 로딩 시에는 받지 않고, 실제로 3D 뷰를 열 때만 불러오도록 개선 (초기 로딩 번들 약 10배 감소)
35. **AI 해석 도우미 (챗봇)** — 자력탐사 결과와 지질도 등 참조 레이어를 종합해 광물자원탐사·근지표 표적탐지 해석을 돕는 채팅 패널. 화면 스크린샷이 아니라 Claude API의 [tool use](https://docs.claude.com/en/docs/agents-and-tools/tool-use/overview)로 실제 프로젝트 자료를 조회(도구 호출)해 답변을 생성합니다.
    - 제공 도구: 측선/자력이상 통계 요약, 3차원 역산 자화율 요약, 오일러 디컨볼루션 결과 요약, 근지표 표적탐지 결과 요약(항목 36), 업로드된 참조 레이어(GeoTIFF) 목록 조회, 특정 위경도 좌표의 실측값 조회(가장 가까운 측점의 자력이상/TMI, 해당 위치의 역산 심도별 자화율, 참조 레이어 픽셀값을 한 번에 종합)
    - 참조 레이어 업로드(항목 17) 시 지도 표시용 이미지와는 별도로, 챗봇이 실제 픽셀값을 조회할 수 있도록 프로젝트에 원본 GeoTIFF 사본도 함께 보관합니다.
    - 자력탐사만으로는 암종·광종이나 근지표 표적의 정확한 종류를 특정할 수 없다는 점, 수치는 반드시 도구로 조회한 실제 값만 인용한다는 점, 표적탐지 맥락에서는 실제 위치 확인·처리에 EOD 등 전문 인력이 필요하다는 점을 시스템 프롬프트로 명시했습니다.
    - **배포 시 별도의 `ANTHROPIC_API_KEY` 환경변수가 필요합니다** — 이 앱을 실행하는 서버(백엔드) 환경에 설정해야 하며, Claude Code 세션 자체의 API 접근과는 무관한 별도 키입니다. 키가 없으면 채팅 시도 시 안내 메시지가 표시됩니다.
36. **근지표 표적탐지 (지뢰·불발탄·은닉 차량 등)** — 왼쪽 사이드바 상단의 "용도" 토글로 "🎯 근지표 표적탐지" 모드를 선택하면 활성화되는 별도 분석 기능. 넓은 지역의 완만한 지질체를 가정하는 광물자원탐사용 3차원 역산/오일러 디컨볼루션과 달리, 작고 국지적인 강자성 표적 하나하나를 찾아 위치·심도·상대적 철질량 크기를 추정합니다.
    - **방법**: 자력이상을 촘촘한 격자(기본 1m)로 만든 뒤, 국지적 극값(local maximum)만 후보로 고르고(완만한 지질 배경은 극값 자체가 없어 자동으로 제외됨) 각 후보를 실측 포인트에 대해 단일 유도자화 자기 쌍극자(magnetic dipole) 모델로 비선형 최소자승 피팅해 위치(x, y)·심도·쌍극자모멘트(A·m², 상대적 철질량 크기 지표)를 구합니다 — UXO/불발탄 자력탐사 문헌에서 표준적으로 쓰이는 "dipole fit" 기법입니다. 후보 크기(footprint)는 절대 진폭 임계값이 아니라 반진폭(half-amplitude) 폭으로 측정해, 강한 신호를 내는 큰 표적의 판정 반경이 부풀어 오히려 "넓은 지질 배경"으로 오분류되는 문제를 피합니다.
    - **용도 전환 시**: 격자 크기 기본값이 광물탐사용(10m)에서 표적탐지용(1m)으로 자동 전환되고, 3차원 역산/오일러 패널은 접힌 상태(고급, 필요시 펼침)로, 표적탐지 패널은 펼쳐진 상태로 바뀝니다.
    - **결과**: 표적 후보 목록(심도, 쌍극자모멘트, 크기등급, 첨두이상값, 적합도)을 표로 표시하고 지도 위에 마커로 겹쳐 표시(마커 크기는 모멘트 로그값에 비례). 처리 보고서(.md)에도 별도 절로 포함됩니다.
    - ⚠ **자력탐사만으로 표적의 정확한 종류(지뢰/포탄/전차/단순 고철 등)를 식별할 수 없습니다.** 쌍극자모멘트 기반 크기등급은 문헌상의 대략적인 order-of-magnitude 구간일 뿐 검증된 분류기가 아니며, 최소금속(low/minimal-metal) 물체는 자력 신호가 거의 없어 애초에 탐지되지 않을 수 있습니다. **실제 위치 확인·접근·처리는 반드시 EOD(폭발물처리반) 등 전문 인력이 현장에서 수행해야 합니다** — 이 기능의 결과만으로 안전을 판단하거나 접근해서는 안 됩니다.
    - 관측면을 평평한 기준면으로 가정하는 단순화는 오일러 디컨볼루션과 동일합니다 — 심도는 그 기준면 기준이며, 실제 매설 심도와는 드론 비행고도(AGL)만큼 차이가 있을 수 있습니다.
    - 격자가 지나치게 촘촘하고(격자 크기를 매우 작게, 조사 영역은 넓게) 예상 셀 수가 상한(4,000,000)을 넘으면 실행 전에 오류로 안내됩니다 — 격자 크기를 늘리거나 관심 영역만 남기고 재시도하세요.
37. **자료 품질검사(QC) 자동화** — 드론/베이스 CSV 로딩 시 중복된 시각(같은 파일 재업로드, 로거 중복 기록 등)과 비정상 좌표(위경도 범위 밖, GPS 미수신 시 흔한 (0,0) 값)를 자동으로 제거하고, 제거된 개수를 업로드 요약에 표시합니다.
38. **필터 종류 선택** — 기존 Butterworth 저역통과(영위상)에 더해 Savitzky-Golay(다항식 평활화, 이상체 봉우리 보존에 유리)와 이동평균 중에서 선택할 수 있습니다. Butterworth 선택 시, 드론 자료의 평균 비행속도를 기반으로 "이 정도 파장의 이상체는 보존하고 싶다"는 값을 입력하면 권장 차단주파수를 계산해 한 번에 적용하는 도우미도 함께 제공됩니다.
39. **좌표계 수동 지정** — 기본적으로 측선 중심 위치로 UTM 구역을 자동 감지하지만, 특정 EPSG 코드를 직접 지정할 수도 있습니다(예: 조사 영역이 UTM 구역 경계에 걸쳐 있어 자동 감지 결과를 다른 프로젝트와 맞추고 싶을 때). 실제 사용된 좌표계는 처리 요약에 EPSG 코드로 표시됩니다.
40. **파생 그리드 4종 추가**
    - **THDR(총수평미분)** — 자화 방향에 무관하게 이상체 경계에서 뚜렷하게 나타나는 수평 변화율 크기로, 접촉면·경계 파악에 RTP/1VD와 함께 참고할 수 있습니다.
    - **상방연속(Upward continuation)** — 지정한 높이만큼 더 높은 고도에서 측정한 것처럼 계산을 재구성해, 짧은 파장(얕고 좁은) 잡음을 광역 신호보다 훨씬 빠르게 감쇠시킵니다.
    - **추세면 제거(Detrend)** — 완만한 광역 배경을 다항식(1~3차)으로 최소자승 적합해 뺀 잔차만 표시해, 얕은 국지 이상을 광역 추세와 분리해 볼 수 있습니다.
    - **마이크로레벨링(디코러게이션)** — 측선과 나란한 방향, 측선 간격 규모의 파장을 갖는 줄무늬 잡음만 골라 파수영역 방향성 노치 필터로 완화합니다. 헤딩/타이라인 보정 후에도 남는 줄무늬가 있을 때 사용하는 표준 항공자력 처리 기법입니다(Geosoft 등 상용 소프트웨어의 decorrugation 필터와 동일한 개념).
41. **측선 프로파일 뷰** — "7. 수동 측선 편집"의 각 측선 목록에서 📈 아이콘을 누르면 해당 측선의 거리-값(자력이상/TMI) 그래프를 볼 수 있습니다. 제외된 포인트는 빨간 점으로 표시되어, 지도의 색상 패턴만으로는 알기 어려운 스파이크·드리프트·레벨링 오차를 측선 단위로 직접 확인할 때 유용합니다.
42. **XYZ(텍스트) 내보내기** — GeoTIFF에 더해, 그리드/파생그리드 결과를 경도·위도·값 3열의 공백 구분 일반 텍스트(XYZ)로도 내보낼 수 있습니다. GeoTIFF를 지원하지 않는 프로그램에서도 열람 가능합니다.
43. **처리된 포인트 전체 CSV 내보내기** — 위경도·로컬 좌표·자력이상·TMI·측선 번호·제외 여부까지 담은 전체 포인트 목록을 CSV로 다운로드할 수 있습니다.
44. **다중 장비 CSV/ASC 자동 포맷 감지** — 기존 일반(Geometrics MagArrow 호환) 포맷에 더해, 파일 헤더를 자동 인식해 MicroInfinity Mag(22열 CSV, TOW 기반), SENSYS MagDrone R1(TMI 컬럼 포함 CSV), SENSYS MagDrone R3 원시 로그(세미콜론 구분 이중 프로브), SENSYS MagDrone R3 ASC(1차 처리 결과물) 파일을 별도 지정 없이 업로드만으로 처리합니다. 인식된 형식은 업로드 요약에 표시됩니다.
45. **한국 좌표계(Korea Projection) 옵션** — 기본 UTM 자동감지 외에, KoreaUTM(EPSG:5179, GRS80 기반 한국 통합 좌표계), Korea2010(EPSG:5185~5188, 경도대별 벨트 좌표계), 국내 UTM(51N/52N) 중에서 선택할 수 있습니다. 국내 관공서·측량 표준과 맞추고 싶을 때 유용합니다.
46. **파생 그리드 확장 (Tilt/Theta/2VD/그래디언트 텐서)** — 기존 RTP/RTE/1VD/AS/THDR/상방연속/추세면제거/마이크로레벨링에 더해, 틸트각(Tilt Angle, 이상체 진폭 크기와 무관하게 경계에서 0을 지나감)·세타맵(Theta Map)·2차 수직미분(2VD)·1·2차 동서/남북/혼합 미분(dX/dY/dXX/dYY/dXY/dXZ/dYZ) 총 9종을 추가로 제공합니다.
47. **Surfer GRD/BLN 내보내기** — 그리드/파생그리드 결과를 Surfer 6 Binary Grid(.grd, DSBB) 형식으로, 지도에서 그린 영역을 Surfer Blanking File(.bln)로 내보낼 수 있어 Golden Software Surfer 워크플로와 바로 연동됩니다.
48. **Adaptive Hampel 스파이크 제거** — 기존 이동중앙값+MAD 방식에, 인접 샘플 기울기가 급변하는 구간(진짜 경사 신호일 가능성)에서는 창 크기를 자동으로 넓혀 비교하는 적응형 로직을 추가해 진짜 신호를 스파이크로 오판하는 것을 줄였습니다(켜고 끌 수 있음).
49. **최소곡률(Minimum Curvature) 격자화** — 기존 원본셀/선형/큐빅/스플라인에 더해, Golden Software Surfer의 기본 격자화 알고리즘과 동일한 Briggs(1974) 최소곡률 방식을 선택할 수 있습니다. 데이터를 지나는 매끄러운 곡면을 반복법(damped relaxation)으로 구해 잠재장 자료에 적합한 결과를 냅니다.
50. **반복(iterative) 네트워크 타이라인 레벨링** — 기존에는 타이라인을 완전히 고정된 기준으로 취급했지만, 새 옵션(기본 켜짐)은 측선과 타이라인의 보정값을 번갈아 재추정하며 오차를 양쪽에 고르게 분산하는 소규모 네트워크 조정을 수행합니다. 기존 방식(타이라인 고정)도 선택적으로 유지됩니다.
51. **PCA 자동 방향 검출 + 전용 비행경로 편집기** — 측선 방향 판별을 기존 진행방향 히스토그램 대신, 측점 분포의 주축(PCA)으로 검출하는 방식도 선택할 수 있습니다. 또한 "7. 수동 측선 편집"에서 "비행 경로 편집기 열기" 버튼으로 위경도 지도가 아닌 투영 좌표(미터) 평면에서 확대/축소하며 드래그로 영역을 제거(Cut)/복원(Restore)할 수 있는 전용 편집기를 제공합니다(DroneMagAdv의 FlightPathDlg 방식 참고).
52. **노이즈 QC (정규화 4th/8th difference)** — Near-Surface Geophysics Inter-Society Committee의 UAV 자력탐사 가이드라인이 표준 항공자력 노이즈 지표로 제시하는 정규화 4차/8차 차분을 측선별로 자동 계산해 처리 요약에 표시합니다. 다른 측선보다 눈에 띄게 노이즈가 큰 측선은 자동으로 플래그됩니다.
53. **지각적으로 균일한 Cubehelix 컬러맵** — 기존 레인보우 계열 컬러맵(Geosoft Rainbow 등)은 특정 색상 구간에서 지각적 대비가 낮아져 이상대가 가려지는 문제가 있는데(위 가이드라인이 구체적으로 지적), 이를 피하도록 설계된 Cubehelix(Green, 2011) 컬러맵을 컬러맵 목록에 추가했습니다.
54. **그리드 셀 크기 가이드 경고** — 가이드라인의 "셀 크기 = 측선 간격의 1/4~1/5" 권장 규칙에서 크게 벗어난 셀 크기를 지정하면(너무 성기거나 너무 촘촘함) 범례 아래에 경고를 표시합니다.
55. **반복측선(Repeatability) 분석** — 가이드라인이 권장하는 실측 노이즈 봉투 산출 절차: 같은 구간을 여러 번(왕복 포함) 비행한 별도의 테스트 비행 자료를 업로드하면, 반복 통과를 자동으로 그룹핑해 1/2/3-시그마 노이즈 봉투와 정방향-역방향 헤딩오차를 계산합니다("15. UAV 자력탐사 가이드라인 진단 도구" 패널).
56. **파워스펙트럼 진단 + 노치필터** — 측선 하나를 선택해 원시 자력신호의 파워스펙트럼(Welch)을 확인하고, 드론 모터 회전(~45-60Hz)이나 흔들림(~0.1-0.6Hz) 같은 특정 간섭 주파수가 피크로 보이면 한 번의 클릭으로 노치필터에 등록해 다음 처리 실행 시 제거할 수 있습니다.
57. **멀티스케일 엣지 검출 (Worming)** — 여러 상향연속 고도에서 총수평도함수(THDR) 능선을 추출해 지질 경계/구조선을 개략적으로 매핑하는 가벼운 도구입니다. 오일러 디컨볼루션보다 빠른 개관용이며, 지도에 상향연속 고도별로 색이 다른 점으로 표시됩니다.
58. **파일(타일) 간 레벨 불일치 자동 감지** — 서로 다른 시점/베이스 위치로 나눠 업로드한 여러 드론 CSV 파일 사이에 자력 이상값의 DC 레벨 차이(가이드라인이 지적하는 대표적 아티팩트 원인 - 베이스 위치 이동 등)가 있으면 처리 요약에 경고로 표시합니다.
59. **디코러게이션 규칙 안내 툴팁** — 측선방향 평활화/마이크로레벨링 파장 관련 입력란에 가이드라인의 필터 길이 권장 규칙(저역통과=타이라인 간격×2, 고역통과=측선 간격×2)을 안내하는 툴팁을 추가했습니다.
60. **Boxing 격자화 방법** — 기존 원본셀/선형/큐빅/스플라인/최소곡률에 더해, 가이드라인이 소개하는 "Boxing"(빈 셀에는 보간하지 않고 실측값이 있는 셀만 그 평균으로 채우는 방식)을 선택할 수 있습니다. 자료가 없는 구간을 억지로 채우지 않고 있는 그대로 보여주고 싶을 때 유용합니다.
61. **정규분포 색상 스트레치** — 기존 선형/히스토그램 균등화 스트레치에 더해, 값 분포를 정규분포로 가정하고 평균·표준편차 기반으로 색상을 배분하는 스트레치 옵션을 추가했습니다.
62. **샘플링 거리 히스토그램(QC)** — 측선 내 연속된 두 측점 사이의 실제 이동거리를 히스토그램으로 계산해 처리 요약에 표시합니다. GPS 순간 끊김(dropout)으로 특정 구간만 샘플 간격이 크게 벌어진 경우를 감지하는 가이드라인 권장 QC 지표입니다.
63. **폴리노미얼(1차) 타이라인 레벨링** — 기존에는 측선별로 상수(0차) 오프셋만 보정했지만, 새 옵션은 각 측선을 따라 선형으로 변하는 오차(1차 다항식)까지 함께 추정해 보정합니다. 타이라인이 2개 이상 있어 교차점이 남북으로 퍼져 있을 때 더 정확한 레벨링이 가능합니다(비반복 모드 한정).
64. **3차원 역산 자동 정규화(Discrepancy Principle)** — 정규화 강도를 수동으로 조정하는 대신, 예상 관측 잡음수준(nT)을 입력하면 역산 잔차(RMS)가 그 수준에 가까워지도록 정규화 강도를 자동으로 탐색합니다(UBC-GIF/SimPEG 방식의 discrepancy principle). 비음수 제약으로 인해 정규화-잔차 관계가 단조롭지 않은 구간까지 고려한 2단계(격자 탐색 후 이분탐색) 탐색과, 실제 IRLS 압축(compact) 재가중이 반영된 잔차 지형을 미리 한 번 추정(snapshot)해 탐색 목표로 삼는 보정을 적용해 신뢰성을 높였습니다.
65. **3차원 역산 심도별 해상도(민감도) 진단** — 민감도 행렬의 레이어별 평균 크기를 계산해, 측선 배치·비행고도상 실제로 잘 구속되는 심도와 그렇지 않은(민감도가 최상층 대비 5% 미만) 심도를 자동으로 구분합니다. 결과 요약과 수평 섹션 뷰 깊이 슬라이더에 레이어별 막대 그래프/경고로 표시되어, 깊은 레이어의 역산 결과를 과신하지 않도록 돕습니다.
66. **수직 단면 뷰 개선** — 기존의 단순 픽셀 이미지 대신, 실제 거리(m)·고도(m) 축과 눈금, 지표면 굴곡을 나타내는 선, SI 컬러바가 있는 제대로 된 도면으로 렌더링합니다. 또한 좌측 상단에 전체 조사구역 범위와 현재 단면의 위치(A–A')를 함께 보여주는 위치도(locator inset)를 추가해, 잘라낸 단면이 전체 조사지역 어디에 해당하는지 바로 확인할 수 있습니다.
67. **수평 섹션 뷰 실제 심도 표시** — 깊이 레이어 슬라이더가 이제 레이어 인덱스뿐 아니라 실제 고도(m)를 함께 보여주고, 얕음/깊음 양끝 고도값과 항목 65의 레이어별 해상도 경고도 슬라이더 옆에 함께 표시됩니다. 지도 범례에도 현재 표시 중인 슬라이스의 실제 고도가 나타납니다.
68. **SI 연속 컬러링 박스 단면(펜스 다이어그램) 3D 뷰** — 기존의 "임계값 이상만 표시하는 매끈한 덩어리" 뷰에 더해, 상단 수평면 + 4개 측벽 전체를 임계값 없이 하나의 연속 SI 컬러스케일로 보여주는 새 3D 표시 모드를 추가했습니다(발표용 3차원 역산 그림에서 흔히 쓰이는 색칠된 상자 스타일). 상단면의 깊이 레이어는 슬라이더로 바꿔가며 확인할 수 있고, 두 뷰(덩어리/박스단면) 사이는 버튼 하나로 전환됩니다.
69. **베이스 시간 오프셋 시/분/초 입력** — 기존 "초" 단일 입력 대신 시/분/초를 각각 입력할 수 있어, 몇 시간 단위로 어긋난 베이스 로거 시계도 정확하게(예: 1시간 23분 45초) 보정값을 계산할 필요 없이 바로 입력할 수 있습니다.
70. **이착륙 구간 자동 식별 + 숨김/보호** — 실제 이륙 지점부터 첫 측선 시작까지, 마지막 측선 종료부터 착륙 지점까지의 "이착륙 구간"을 자동으로 식별해 측선 편집기에서 기본적으로 숨기고, 제외/복원 영역 그리기의 대상에서도 제외합니다(켜면 다시 표시/편집 가능). 실수로 이착륙 구간을 측선 자료로 착각해 편집하는 것을 방지합니다.
71. **측선 내 일시적 이탈 구간 브릿징** — 바람 등으로 위치/헤딩이 순간적으로 측선판별 기준을 벗어나도, 경로 길이·직선 대비 우회 정도(직선성)로 볼 때 같은 물리적 측선이 명백하면 자동 제외하지 않고 그 구간을 이어 붙여(bridging) 측선을 끊기지 않게 유지합니다. 실제 턴(방향전환)/캘리브레이션 루프는 직선성 기준으로 구분해 여전히 제외됩니다.
72. **베이스(일변화) 자료 자동 QC + 원본/보정 비교 그래프** — 베이스 로거를 설치/회수할 때 흔들리며 기록되는 큰 진폭의 노이즈 구간을 자동으로 감지해 시작/끝에서 트림하고, 정착된 구간 중간에 있는 비정상적으로 튀는 값(스파이크)은 로버스트 통계(중앙값+MAD)로 검출해 주변 값으로 매스킹합니다(측선 despike와 같은 원리를 베이스 로그에 적용). 처리 요약과 "베이스 원본/보정 자료 그래프 보기" 버튼을 통해 원본과 보정 후 자료를 시계열 그래프로 겹쳐 비교할 수 있습니다.
73. **측선 프로파일 원본 vs 처리후 비교 + 왜곡 구간 수동 스무딩** — 측선 프로파일 그래프에 필터링(디스파이크+노치+저역통과) 전 원본 신호를 처리 후 신호와 겹쳐 표시해, 자료처리 과정에서 없어진(또는 없어져야 했는데 남은) 자료를 눈으로 확인할 수 있습니다. 지상 구조물(집, 건물 등)로 인한 왜곡이 보이는 구간은 그래프를 드래그해 선택한 뒤 "스무딩 적용" 버튼으로 주변 정상 값 사이를 선형 보간해 제거할 수 있습니다. 같은 기능을 지도에서도 사용할 수 있어, 참조 레이어로 드론 정사영상(orthophoto)을 업로드해 구조물 위치를 눈으로 확인하며 그 위에 영역을 그려 왜곡을 제거할 수 있습니다.
74. **베이스 자료 없이 처리 진행 (지구자기장 일정 가정)** — 베이스(일변화) 자료를 측정하지 못했을 때, 일변화 보정 방식을 "베이스 자료 없음"으로 설정하면 지구자기장이 조사 기간 동안 일정했다고 가정하고 드론이 측정한 값을 그대로 사용해 다음 단계로 진행할 수 있습니다(수학적으로는 완전히 일정한 베이스 값으로 보정하는 것과 동일한 결과). 태양풍 등에 의한 시간에 따른 자기장 변화(일변화)는 보정되지 않는다는 경고가 함께 표시됩니다.
75. **INTERMAGNET 관측소 자료로 베이스 자료 대체** — 로컬 베이스 자료가 없을 때, 전 세계 지자기 관측소 네트워크인 [INTERMAGNET](https://intermagnet.org)의 공개 자료를 대신 활용해 일변화 보정을 할 수 있습니다. 로컬(측정 지역 고유)한 일변화까지는 반영하지 못하지만, 태양풍에 의한 지역/전지구적 자기장 변화는 인근 관측소 자료로 추정할 수 있습니다(일변화 보정은 베이스 값의 절대 수준이 아니라 조사 시간창 평균 대비 *변화량*만 사용하므로, 원거리 관측소의 절대 자기장 차이는 자동으로 상쇄됩니다). 두 가지 방법을 지원합니다: (1) intermagnet.org에서 직접 받은 IAGA-2002 형식 파일을 업로드 — 서버의 네트워크 접근 여부와 무관하게 항상 동작, (2) 관측소 코드(IAGA 코드)와 날짜를 입력하면 서버가 BGS INTERMAGNET Global Node에서 자동으로 받아옴 — 서버 배포 환경의 아웃바운드 네트워크 정책에 따라 막혀 있을 수 있으며, 이 경우 (1)번 방법을 사용하세요. 두 경우 모두 관측소명·위치·조사지역까지의 거리·자료 기간을 먼저 보여주는 미리보기 단계를 거친 뒤 "이 자료를 베이스 자료로 사용" 확인을 눌러야 실제로 적용됩니다.

## 실행 방법

### 백엔드

```bash
cd backend
pip install -r requirements.txt
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

`--reload`를 붙이면 프론트엔드(Vite)처럼 코드가 바뀔 때마다 서버가 자동으로 재시작됩니다 — 매번 터미널에서 껐다 켤 필요가 없습니다. (다만 코드 저장 후 서버가 재시작되는 짧은 순간에는 요청이 실패할 수 있으니, 재시작 로그가 끝난 뒤 새로고침하세요.)

AI 해석 도우미(챗봇, 기능 35)를 쓰려면 백엔드 실행 전에 `ANTHROPIC_API_KEY` 환경변수를 설정하세요. 설정하지 않아도 나머지 기능은 모두 정상 동작합니다.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

### 프론트엔드

```bash
cd frontend
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173` 접속 (Vite 개발서버가 `/api` 요청을 백엔드 8000 포트로 프록시합니다).

### 통합 테스트

실제 샘플 자료(`backend/tests/fixtures/`)로 전체 파이프라인을 API 레벨에서 검증합니다.

```bash
cd backend
python3 tests/test_pipeline_e2e.py
```

## 알려진 제약사항

- **배경지도 타일**: OSM/Esri/Google 타일은 사용자의 브라우저가 직접 요청합니다(백엔드가 프록시하지 않음). 사내망/방화벽 환경에서 해당 타일 서버로의 아웃바운드가 막혀 있으면 지도 배경이 표시되지 않을 수 있습니다.
- **INTERMAGNET 자동 다운로드**: 이 기능은 백엔드 서버 자신이 BGS INTERMAGNET Global Node(imag-data.bgs.ac.uk)로 아웃바운드 HTTPS 요청을 보낼 수 있어야 동작합니다. 사내망/방화벽/샌드박스 환경에서 해당 호스트로의 접근이 막혀 있으면 "자동 다운로드 시도"가 실패하니, 이 경우 intermagnet.org에서 직접 받은 IAGA-2002 파일을 "IAGA-2002 파일 업로드"로 올리세요(네트워크 접근이 전혀 필요 없습니다). 또한 원격 관측소 자료는 로컬(측정 지역 고유) 일변화까지는 반영하지 못하므로, 가능하면 실제 현장 베이스 측정을 우선하고 이 기능은 대안으로만 사용하세요.
- **베이스 로거 시계 오프셋**: 베이스 자력계가 GPS 시각에 동기화되지 않은 경우가 흔합니다. 처리 요약에 베이스/드론 시간범위가 겹치지 않는다는 경고가 표시되면 "베이스 시간 오프셋(초)" 값을 조정하세요.
- **Google 위성 타일**은 비공식 XYZ URL이라 이용약관(ToS) 상 상업적 대량 사용에는 적합하지 않을 수 있습니다. 정식 서비스에는 Google Maps Platform API 키 사용을 권장합니다.
- 프로젝트 상태는 서버 메모리에만 저장됩니다(재시작 시 소실). 여러 사용자가 동시에 쓰는 배포 환경에는 별도의 영속 저장소가 필요합니다.
- **헤딩 보정**은 정식 캘리브레이션(figure-8) 비행 기반 보정이 아니라, 인접한 반대방향 측선의 조용한 구간을 비교하는 단순화된 추정치입니다. 측선이 2개 미만이거나 모두 같은 방향으로 비행된 경우 자동으로 건너뜁니다.
- 그리딩 보간 반경을 비워두면(자동) 검출된 측선 간격의 0.6~1.5배를 기준으로 계산합니다. 측선 간격이 고르지 않은 조사에서는 "보간 반경(m)" 값을 직접 조정하는 것이 더 정확할 수 있습니다.
- **GeoTIFF 참조 레이어**는 원본 픽셀 격자를 그대로 유지한 채 네 모서리만 위경도로 변환해 사각형 범위로 근사 표시합니다. 좌표계가 정북 기준으로 크게 회전되어 있지 않은 일반적인 경우에는 문제없지만, 회전이 큰 좌표계에서는 약간의 왜곡이 있을 수 있습니다. 업로드 이미지는 브라우저 메모리 문제를 피하기 위해 긴 변 기준 2000px로 축소되어 표시됩니다.
- **타이라인(교차점) 레벨링**은 정식 동시 네트워크 최소자승 조정(모든 측선+타이라인을 함께 푸는 방식)이 아니라, 타이라인 값을 고정된 기준으로 두고 각 측선에 하나의 상수(DC shift) 보정만 적용하는 단순화된 방식입니다. 타이라인 자체의 레벨링 오차가 있다면 그대로 측선에 전파됩니다.
- **오일러 디컨볼루션**은 관측면을 평평한 기준면(비행 고도 일정 가정)으로 단순화하며, 구조지수를 사용자가 직접 선택해야 합니다(자동 판별 없음) - 실제 이상체의 기하와 다른 구조지수를 고르면 심도 추정이 부정확해집니다. 3차원 역산처럼 정밀한 결과가 아니라 빠른 개략적 위치·심도 참고용입니다.
- **처리 보고서**는 PDF가 아니라 Markdown(.md)으로 생성됩니다 — 별도 네이티브 PDF 라이브러리 의존성 없이 어떤 텍스트 편집기에서도 열리고 GitHub 등에서 바로 렌더링되며, PDF가 필요하면 브라우저 인쇄나 pandoc 등으로 손쉽게 변환할 수 있습니다.
- **그래디오미터(듀얼 센서) 자료는 지원하지 않습니다** — 로드맵 섹션에 범위 평가를 정리해 두었습니다.
- **AI 해석 도우미(챗봇)**는 `ANTHROPIC_API_KEY` 환경변수가 설정된 배포 환경에서만 동작합니다. 도구가 실제로 조회하는 것은 이 프로젝트가 처리한 자료(측선 통계, 역산, 오일러 디컨볼루션, 표적탐지, 업로드한 참조 레이어)뿐이며, 인터넷 검색이나 외부 지질/군사 DB 조회는 하지 않습니다 — 최종 해석 판단과 현장 검증은 사용자의 몫입니다.
- **근지표 표적탐지**는 자동/수동 그래디오미터 보정 없이 단일 센서 자료 기준으로 설계되어, 넓은 지역에서는 일변화 잔차나 완만한 지질 배경 변화가 표적 탐지의 잡음원이 될 수 있습니다(그래디오미터 지원은 로드맵의 미구현 항목으로 남아 있습니다 - 장비 구축 후 재검토 예정). 단일 쌍극자 모델은 서로 가까이 묻힌 여러 표적을 하나로 뭉뚱그려 피팅할 수 있고, 비자성 재질(플라스틱케이스 지뢰 등)이나 극소량의 금속만 포함한 물체는 원리상 탐지 대상이 아닙니다.
- **마이크로레벨링(디코러게이션)**은 측선 방향·측선 간격 규모의 파수 성분을 방향성 필터로 완화하는 방식이라, 실제 지질 이상체가 우연히 측선과 나란한 방향으로 길게 늘어서 있고 그 폭이 측선 간격과 비슷하다면 일부 감쇠될 수 있습니다 — 적용 전후 그리드를 비교해 실제 이상체가 약해지지 않았는지 확인하세요. 보정 강도를 낮추면 영향을 줄일 수 있습니다.
- **좌표계 수동 지정**은 EPSG 코드가 유효한 투영 좌표계를 가리켜야 합니다(위경도 지리좌표계 EPSG 코드를 넣으면 처리 중 오류가 납니다). 잘못 입력하면 처리 실행 시 오류 메시지로 안내됩니다.
- **MicroInfinity Mag / SENSYS MagDrone R3 ASC 형식**은 파일 자체에 달력 날짜가 없고(GPS 초/타임스탬프[ms]만 존재), 처리 시점(서버 처리 당일)을 임시 기준 날짜로 사용합니다 — 같은 날 처리하는 베이스스테이션 로그와는 실제 절대시각이 어긋나 일변화 보정이 겹치지 않을 수 있습니다. 가능하면 같은 날 업로드/처리하거나, 이 두 형식은 날짜 정보가 있는 다른 장비 포맷으로 변환 후 사용하는 것을 권장합니다.
- **최소곡률(Minimum Curvature) 격자화**는 감쇠(damped) 반복법으로 구현되어 있어, 다른 방법보다 계산이 다소 오래 걸릴 수 있습니다(그리드 규모에 따라 최대 수백 ms~수 초).
- **비행 경로 편집기**는 DroneMagAdv의 FlightPathDlg를 참고했지만, 기울어진 사각형/평행사변형 선택이나 PCA 가이드 각도 등 고급 선택 도구는 제공하지 않고 팬·확대/축소·축정렬 사각형 자르기(Cut)/복원(Restore)만 지원하는 단순화된 버전입니다.
- **3차원 역산**은 실험적 기능입니다:
  - 관측점을 원시 포인트가 아니라 기존 그리딩 수준(격자 크기 기준 최대 3,000점)으로 축소하고, 메쉬도 활성 셀 기준 최대 70,000개로 제한합니다 - 더 상세하게(격자를 촘촘히, 레이어를 많이) 설정할수록 정규방정식을 여러 번 푸는 비용이 커져 실행 시간이 최대 1~2분까지 늘어날 수 있습니다. 매우 조밀한 역산은 지원하지 않으며, 상한을 넘으면 오류 메시지와 함께 거부됩니다.
  - 조사 영역이 넓으면 이 상한들 때문에 자동/수동으로 설정한 격자 크기가 실제 측선 간격보다 커질 수 있습니다(예: 측선 간격 100m인데 셀 크기 150m) - 이 경우 결과 요약에 경고가 표시되며, 측선 자료가 가진 해상도를 다 살리지 못한다는 뜻입니다. 관심 영역만 남기고 나머지 측선을 수동 제외한 뒤 다시 역산하거나, 자동 설정을 끄고 셀 크기를 직접 낮추면(실행 시간 증가) 더 세밀한 결과를 얻을 수 있습니다.
  - 파라미터를 비워두면(기본값) 측선 간격과 자력이상 그리드의 방사평균 파워스펙트럼 기울기로부터 격자 크기·탐사 심도·레이어 수를 자동 산정합니다. 스펙트럼 심도 추정은 개별 이상체가 아니라 전체 자료의 "특징적인" 평균 심도를 근사하는 통계적 기법(Spector & Grant 1970)이라, 심도가 서로 크게 다른 이상체들이 섞여 있으면 자동값이 최적이 아닐 수 있습니다 - 자동 설정을 끄고 직접 조정하세요.
  - DEM 없이 GPS로 추정한 지형은 등고비행 가정(일정 AGL) 하의 **상대적** 굴곡만 정확하며, 절대 고도 기준은 사용자가 입력한 AGL 값에 의존하는 근사치입니다.
  - UBC 스타일의 자동 베타 쿨링(discrepancy principle) 없이 고정 반복 횟수 + 사용자 조정 "정규화 강도" 배수로 단순화했습니다. 사전정보가 없는 역산 특성상 해가 유일하지 않으며(non-unique), 특히 근지표에 국소적으로 강한 이상이 있는 실제 자료에서는 일부 셀의 자화율이 물리적 상한(SI 1.0, 안전장치용 상한일 뿐 결과를 임의로 제한하지 않습니다)까지 올라갈 수 있습니다 - 이 경우 정규화 강도를 높이거나 표시 임계값을 조정해 확인하세요.
  - 유도자화(induced magnetization)만 가정하며 잔류자화(remanence)는 고려하지 않습니다 - 이 역시 사전정보 없는 역산에서 흔히 쓰이는 표준적 단순화입니다.
  - 자화율 자체의 절대값보다는 **상대적 위치·형태(어디에 이상대가 뭉쳐 있는지)**를 참고하는 용도에 적합합니다.

## 로드맵 (다음 단계로 논의된 항목, 아직 미구현)

- TMI/RTP 이미지에서 비행고도·이상대 크기 입력 기반 간이 심도 추정 등 2D 해석 도구

### 그래디오미터(듀얼 센서) 지원 - 범위 평가 (미구현)

두 개의 자력계를 수직(또는 수평)으로 일정 간격 이격해 장착하고, 두 센서 값의 차이를 측정 간격으로 나눈 **자력 구배(magnetic gradient, nT/m)**를 직접 얻는 방식입니다. 실측 구배는 단일 센서의 전자력값보다 일변화(diurnal) 영향에 훨씬 덜 민감하고(두 센서가 거의 동시에 같은 배경 변화를 겪어 차분 시 상쇄됨), 얕고 작은 이상체의 경계를 더 날카롭게 드러내는 장점이 있어 UXO 탐사나 정밀 고고물리탐사에서 널리 쓰입니다.

지금까지 진행한 개선들과 달리 이 기능은 기존 파이프라인에 파라미터 하나를 추가하는 수준이 아니라, 다음과 같이 여러 층위에 걸친 구조적 변경이 필요해 이번 라운드에서는 구현하지 않고 범위만 검토했습니다:

- **입력 자료 형식**: 현재 `io_/drone_loader.py`는 한 타임스탬프당 자력값 하나를 전제로 합니다. 듀얼 센서는 로거마다 컬럼 구성이 제각각이라(상단Mag/하단Mag 별도 컬럼, 또는 완전히 별도 파일 2개를 타임스탬프로 매칭 등) 새로운 전용 로더와 두 센서 간 시간 동기화 로직이 필요합니다.
- **센서 간 레벨링(사전 캘리브레이션)**: 두 센서는 제작 편차로 서로 다른 base level과 heading 민감도를 가지므로, 비행 전 정지 상태 비교 또는 별도 캘리브레이션 절차로 오프셋을 추정해 빼주지 않으면 구배값 자체가 왜곡됩니다 - 현재의 헤딩/타이라인 레벨링과는 별개의, 센서쌍 특유의 보정 단계입니다.
- **처리 파이프라인 분기**: 일변화 보정(diurnal correction)의 역할이 크게 줄어들거나(구배는 이미 대부분 상쇄) 아예 다른 방식의 보정으로 대체되어야 하며, despike/필터도 두 채널에 동일하게 적용한 뒤 차분해야 위상이 어긋나지 않습니다.
- **시각화**: 그리딩·RTP/RTE/1VD/AS 변환 자체는 구배값에도 동일하게 적용 가능하지만, 등고선 간격·컬러 스케일 기본값(구배는 nT가 아니라 nT/m 단위로 훨씬 좁은 동적범위)을 별도로 다뤄야 합니다.
- **3차원 역산**: 현재 역산의 정반응 커널(`processing/inversion.py`)은 전자력(TMI) 단일 관측값 기준입니다. 구배 자료를 직접 역산하려면 `choclo`의 자기장 텐서(gradient tensor) 커널로 정반응 행렬을 다시 구성해야 하며, 이는 새로운 검증(합성모델 테스트)이 필요한 별도 작업입니다.

요약하면, 그래디오미터 지원은 로더-보정-시각화-역산 전 layer에 걸친 별도 기능 트랙에 가까워 이번 요청 범위(기존 단일 센서 파이프라인의 개선)와는 성격이 다릅니다. 실제 듀얼 센서 원시자료 샘플이 있다면 그 스키마를 기준으로 별도 설계·구현 라운드로 진행하는 것을 권장합니다.
