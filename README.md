# DroneMag Studio — 드론 자력탐사 자료처리 프로그램

드론(UAV)으로 취득한 자력탐사 자료를 원시 기록에서 최종 해석 도면까지 하나의 흐름으로
처리하는 프로그램입니다. 로컬 서버(FastAPI)와 웹 화면(React + Leaflet)으로 구성되며,
설치본은 별도 실행환경 없이 Windows에서 단독 실행됩니다.

**프로그램이 무엇을, 왜 그렇게 처리하는지**(이론적 배경, 단계별 알고리듬, 기본값의 실측 근거,
학습 노트)는 [`docs/TECHNICAL_MANUAL.md`](docs/TECHNICAL_MANUAL.md)와 같은 내용의 PDF
[`docs/Magnetic_Processing_Technical_Manual.pdf`](docs/Magnetic_Processing_Technical_Manual.pdf)에
정리되어 있습니다. 이 README는 구성과 실행 방법, 기능 목록만 다룹니다.

## 구성

| 경로 | 내용 |
|---|---|
| `backend/` | FastAPI 처리 서버. `app/processing/`에 처리 모듈 68개, `tests/`에 자동화 시험 |
| `frontend/` | React + Leaflet 지도 화면 |
| `docs/` | 기술 매뉴얼(Markdown, PDF)과 PDF 빌드 스크립트 |
| `packaging/` | PyInstaller 사양(`magnetic.spec`)과 Inno Setup 스크립트(`installer.iss`) |

## 실행

**개발 환경**: `run.bat`을 실행하면 브랜치 갱신, 의존성 설치, 프런트엔드 빌드, 서버 실행,
브라우저 열기까지 자동으로 진행됩니다. 화면 왼쪽 위에 실행 중인 커밋이 표시되므로
"고쳐달라던 문제가 그대로"일 때 먼저 그 값을 확인하세요.

**설치본**: `packaging/output/DroneMagStudioSetup.exe` 하나를 복사해 설치합니다(설치 비밀번호
필요, 사용자 권한으로 설치). 시작 메뉴에 프로그램·기술 매뉴얼·제거 항목이 생깁니다.

설치본을 다시 만들려면:

```bat
backend\venv\Scripts\python.exe -m PyInstaller packaging\magnetic.spec --noconfirm --distpath packaging\dist --workpath packaging\build
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" packaging\installer.iss
```

시험은 `backend/` 안에서 실행합니다(시험 자료 경로가 그 기준입니다):

```bat
cd backend && python -m pytest tests -q
```

## 기능 (화면 단계 순서)

**1–2. 자료 올리기**
- 드론 자력 기록 CSV 여러 개를 한 번에 적재. Date/Time/Lat/Lon/Mag 등 컬럼 자동 인식, GGA 전용
  필드 시간축 보간, 벤더 도구나 `Mag_Heading`이 만든 사전 보정값(`MagComp`) 우선 사용.
- 중복 시각·비정상 좌표 행 제외(파일 안의 재동기 행은 먼저 기록된 것을 남김).
- 기준국(일변화) 기록 적재: 헤더 없는 CSV와 1초 텍스트 형식 자동 인식.
- 기준국이 없거나 빠진 날이 있으면 **INTERMAGNET 관측소 자료를 자동 수집해 합성**. 탐사 전 기간을
  관측소별로 연속 확보한 뒤 공통 기준선으로 맞추고 역거리가중 평균하며, 참여 관측소가 바뀌는
  시점의 단차를 제거합니다. 응답 없는 관측소와 미발표 날짜는 기억해 두어 반복 요청하지 않습니다.
- 헤딩효과 캘리브레이션 비행 파일 적재(2-1).

**5. 필터 · 측선 판별 · 보정**
- GPS–자력계 시간지연 보정, 중앙값·MAD 스파이크 제거, Butterworth/이동평균/Savitzky–Golay
  저역통과, 노치 필터.
- 측선 자동 검출, 끊긴 측선 이어붙이기, 중단 후 재개된 비행의 중복 구간 선택, 이착륙·선회 제외.
- 취득 QC: 정규화 4차/8차 차분 잡음, 샘플 간격, IMU 기반 센서 흔들림 구간 배제.
- 기준국 QC(과도구간 제거, 연속 기록 중 계단 보정), IGRF-14 주자기장 제거.
- 레벨링: 헤딩(왕복) 보정(**기본 꺼짐** — 측정은 항상, 적용은 신뢰도 검사 통과 시만), 타이라인
  교차점 보정, 측선별 통계적 레벨링(기본 켜짐).

**7. 수동 편집**
- 측선 체크박스 또는 지도에 그린 영역으로 제외·복원, 전체 되돌리기.
- **재비행 구간 비교**: 같은 구간을 두 번 난 측선 쌍을 찾아 레벨 차이와 잔차를 재고, 비행별
  레벨을 망조정으로 맞춥니다. 재비행이 없으면 다음 탐사 설계를 안내합니다.
- **7-1 이상 후보 표시 후 수동 제거**: 해석신호 기준으로 후보를 찾아 순위를 매기고(여러 측선이
  확인한 청록 후보 먼저), 소스 깊이와 **자화 방향(유도/잔류)** 판정을 함께 표시합니다.
  제거는 **구조물 모델 차감**(기본) 또는 측선방향 보간. 후보마다 지상구조물/지질/보류 판정과
  메모를 남기고 CSV로 내보낼 수 있습니다.
- 7-2 OpenStreetMap 건물·도로와 이상의 자동 대조.

**8–10. 표시 · 격자 · 파생 격자**
- TMI/자기이상 컬러 지도, 컬러맵 8종, 표시 범위 지정, 값 조회.
- 그리딩: 블록평균 후 최근접/선형(기본)/3차/스플라인/최소곡률/박스 보간, 셀별 국소 측선간격 기반
  외삽 마스킹, 신뢰도 도면, 측선방향 저역통과.
- 파생 격자: RTP/RTE, 1·2차 연직미분, 수평미분, 해석신호, THDR, 틸트각, 상향연속, 추세면 제거,
  마이크로레벨링. 미분 전·후 해상도 한계 필터, 경계 등가소스 연속, 등가 소스층 대체.

**11–12. 배경지도 · 참조 레이어**
- OSM / Esri 위성 / Google 위성 배경지도.
- **KIGAM 지질도**(1:5만 / 1:25만 / 1:100만 / 단층)를 배경 위에 겹치기. WMS를 백엔드가 타일로
  바꿔 제공하므로 오프라인 캐시에 포함됩니다.
- GeoTIFF 참조 레이어(지질도 스캔 등)와 대용량 정사영상용 로컬 타일 폴더.

**13–14. 해석**
- 3차원 자화율 역산(심도가중 Tikhonov + IRLS), 메시 자동 제안, 지질 블록 참조 모델.
- 오일러 디컨볼루션, 틸트·해석신호·스펙트럼 심도 추정, 다중스케일 에지, 리니어먼트 추출과
  장미도, 자성 접촉면 탐지, 소형 표적 쌍극자 적합, 유망도 매핑.
- **14-7 지질 단위별 자력이상 통계**: KIGAM 지질도 폴리곤에 측점을 대응시켜 암상별 평균·산포·
  해석신호를 표로 냅니다.
- 14-1 표준 QC 인증서(기준별 PASS/FAIL, 재비행 반복도 자동 반영).

**15–17. 그 밖에**
- AI 해석 도우미(챗봇), UAV 자력탐사 가이드라인 진단, 오프라인 지도(탐사 범위의 배경지도·지질도
  타일 미리 받기), 거리/면적 측정.
- 내보내기: GeoTIFF, XYZ, Surfer 격자, CSV, 셰이프파일, KML/BLN 경계, 보고서(Markdown).
- 프로젝트 저장·불러오기와 **자동 저장·복구**(2분 간격, 편집이 멈춘 뒤 백그라운드 저장, 재시작 후
  "이전 작업 이어서 하기").

## 설계 원칙

1. **항상 측정하고, 신뢰될 때만 적용한다.** 보정량은 켜지 않아도 계산해 수치로 보여주고, 자체
   신뢰도 검사를 통과할 때만 자료에 적용합니다.
2. **못 하는 것은 추측하지 않는다.** 자료가 부족하면 보정을 건너뛰고 그 이유를 남깁니다.
3. **기본값은 실측으로 정한다.** 합성자료와 실제 탐사자료로 검증한 값만 기본값으로 씁니다. 근거는
   기술 매뉴얼의 인용 상자에 있습니다.
4. **측선 사이는 측정되지 않았다.** 보간이 만든 성분이 미분으로 증폭되지 않도록 처리 단계에서
   차단합니다.
