# 드론 자력탐사 자료 처리 프로그램

드론으로 취득한 자력탐사 자료를 업로드해 필터링, 측선 판별, 일변화/IGRF 보정, 그리딩, RTP/RTE/AS/1VD 파생 그리드까지 처리하는 웹 애플리케이션입니다.

## 구성

- `backend/` — FastAPI 처리 서버 (필터, 측선 자동판별, 일변화 보정, IGRF, 그리딩, FFT 변환)
- `frontend/` — React + Leaflet 지도 UI (업로드, 파라미터 조정, 지도 표시, 수동 측선 편집, 그리드/파생그리드 표시)

## 기능

1. 드론 자력 취득 파일 로딩 — 여러 비행 파일을 동시에 선택하면 하나로 합쳐 처리 (Date/Time/Lat/Lon/Mag 등 컬럼 자동 인식, GGA 전용 필드 시간축 보간)
2. 일변화(베이스 자력계) 자료 로딩 — 여러 로그 파일 동시 업로드 지원 (헤더 없는 CSV, 한글 오전/오후 12시간제 지원)
3. 저주파 통과 필터 (Butterworth, 영위상 filtfilt)
4. 이착륙·터닝구간 등 비측선 자료 자동 판별/제거 (측선 방향 허용오차, 터닝 여분 구간(m) 설정 가능)
5. 일변화 보정 + IGRF 보정 (자력이상 = TMI - IGRF), 베이스 로거 시계 오프셋 보정 지원
6. 위치별 자력값(TMI/이상) 컬러 지도 표시
7. GUI 지도에서 측선 체크박스 또는 폴리곤/사각형 드래그로 추가 수동 제거 — 반대로 자동 판별이 잘못 제외한(비행 흔들림 등) 구간도 "포함(복원) 모드"로 영역을 그려 되살릴 수 있음, "수동 편집 모두 되돌리기"로 완전 자동 상태로 일괄 복귀
8. TMI 값 hover 표시 및 통계(min/max/mean/std)
9. 그리딩 (verde block-mean + 원본 셀(nearest, 기본/빠름)·선형·큐빅·스플라인 보간 선택 가능, 측선 간격 기반 자동 보간 반경으로 측선 사이 공백 최소화)
10. RTP / RTE / 1VD / AS 파생 그리드 (Blakely 1995 방식 FFT 필터, 직접 구현)
11. 배경지도 (OSM, Esri 위성, Google 위성) — Leaflet 레이어 컨트롤로 전환
12. 헤딩(비행방향) 오차 보정 — 캘리브레이션(figure-8) 비행이 없을 때, 인접한 반대방향 측선 쌍 중 국지적 변화가 적은("조용한") 지점들을 찾아 방향별 평균 오프셋을 추정하고 측선별로 레벨링
13. 컬러맵 선택 (Viridis/Plasma/Turbo/RdYlBu/RdBu/Spectral/Grayscale/**Geosoft Rainbow**) 및 표시 범위(min/max) 수동 지정 — 특정 구간(예: 1000~2000nT)만 확대해서 색상 대비를 높여 볼 수 있음
14. 대용량 자료(수십만 포인트)에서도 매끄러운 지도 렌더링 — 포인트마다 개별 마커를 만드는 대신 캔버스에 직접 그리는 방식이라 색상/값 필드 등 옵션 변경 시 즉시 재도색됨
15. 그리드/파생그리드 위에도 측선(포인트) 레이어를 겹쳐 표시 가능(토글), 그리드 오버레이 불투명도 슬라이더 조절
16. 지도에 측선 번호 라벨 표시 토글 — 수동 편집 시 어느 측선이 몇 번인지 바로 확인 가능
17. 좌표계가 내장된 GeoTIFF(지질도 등 참조 자료) 업로드해 배경지도 위에 중첩 표시 — 여러 장 추가 가능하며 각각 표시여부/불투명도/쌓임순서(위·아래 이동) 조절
18. **3차원 자력 역산 (실험적)** — 사전 지질정보 없이 관측 자력이상만으로 지하 자화율(susceptibility) 분포 추정
    - 방법: Li & Oldenburg (1996) 심도가중 Tikhonov 역산 + Portniaguine & Zhdanov (2002) IRLS compact/focusing 재가중 (UBC-GIF MAG3D, SimPEG과 같은 계열의 사실상 표준 기법)
    - 정반응(forward) 계산: Fatiando a Terra의 `choclo` 직육면체 자력장 커널(numba 병렬화, 피어리뷰 검증됨)을 감싼 민감도 행렬 생성
    - 지형: DEM(GeoTIFF) 업로드 가능, 없으면 등고비행(일정 고도) 가정 하에 드론 GPS 타원체고에서 지형 추정 — "활성 셀(active cell)" 방식으로 지형 위 공기층 셀을 역산에서 제외
    - **파라미터 자동 설정**: 격자 크기는 측선 간격 기반, 탐사 심도는 자력이상 그리드의 방사평균 파워스펙트럼 기울기로 이상원 심도를 추정(Spector & Grant 1970)해 자동 산정 — 체크박스 해제 시 수동 지정도 가능. "더 상세한 역산"을 위해 격자를 촘촘히/레이어를 많이 잡을수록 실행 시간이 길어짐(최대 1~2분)을 허용하도록 관측점·활성 셀 상한을 상향
    - 결과 도시: 수평 섹션(깊이별 슬라이더, 지도 위 오버레이), 수직 섹션(자유선을 지도에 그리거나 동서/남북 고정 방향 + 위치 슬라이더로 즉시 조회, 크게 보기 패널), 3차원 이상대 뷰 — 세 가지 도시 모두 SI 값 하한/상한 범위 필터 지원
    - **3차원 이상대 뷰**(Plotly `isosurface`): 지정한 SI 범위(하한/상한)에 속하는 부분만 매끈하고 닫힌 하나의 "덩어리" 표면으로 렌더링 — 실제 역산 셀 크기가 크더라도 표시 직전에 더 촘촘한 격자로 삼중선형(trilinear) 보간해 부드럽게 이어 보이도록 처리(역산 결과 자체는 바뀌지 않음). 박스 상단에는 역산에 사용한 관측 자력이상/TMI 지도를 실제 지형 굴곡을 따라 입혀서(drape) 2D 자료와 3D 역산체의 위치 관계를 한눈에 볼 수 있음(체크박스로 켜고 끌 수 있음) — Oasis Montaj/VOXI류 소프트웨어의 일반적인 3차원 역산 결과 도시 방식을 참고

## 실행 방법

### 백엔드

```bash
cd backend
pip install -r requirements.txt
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### 프론트엔드

```bash
cd frontend
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173` 접속 (Vite 개발서버가 `/api` 요청을 백엔드 8000 포트로 프록시합니다).

### 통합 테스트

실제 샘플 자료(`backend/tests/fixtures/`)로 전체 파이프라인을 API 레벨에서 검증합니다.

```bash
cd backend
python3 tests/test_pipeline_e2e.py
```

## 알려진 제약사항

- **배경지도 타일**: OSM/Esri/Google 타일은 사용자의 브라우저가 직접 요청합니다(백엔드가 프록시하지 않음). 사내망/방화벽 환경에서 해당 타일 서버로의 아웃바운드가 막혀 있으면 지도 배경이 표시되지 않을 수 있습니다.
- **베이스 로거 시계 오프셋**: 베이스 자력계가 GPS 시각에 동기화되지 않은 경우가 흔합니다. 처리 요약에 베이스/드론 시간범위가 겹치지 않는다는 경고가 표시되면 "베이스 시간 오프셋(초)" 값을 조정하세요.
- **Google 위성 타일**은 비공식 XYZ URL이라 이용약관(ToS) 상 상업적 대량 사용에는 적합하지 않을 수 있습니다. 정식 서비스에는 Google Maps Platform API 키 사용을 권장합니다.
- 프로젝트 상태는 서버 메모리에만 저장됩니다(재시작 시 소실). 여러 사용자가 동시에 쓰는 배포 환경에는 별도의 영속 저장소가 필요합니다.
- **헤딩 보정**은 정식 캘리브레이션(figure-8) 비행 기반 보정이 아니라, 인접한 반대방향 측선의 조용한 구간을 비교하는 단순화된 추정치입니다. 측선이 2개 미만이거나 모두 같은 방향으로 비행된 경우 자동으로 건너뜁니다.
- 그리딩 보간 반경을 비워두면(자동) 검출된 측선 간격의 0.6~1.5배를 기준으로 계산합니다. 측선 간격이 고르지 않은 조사에서는 "보간 반경(m)" 값을 직접 조정하는 것이 더 정확할 수 있습니다.
- **GeoTIFF 참조 레이어**는 원본 픽셀 격자를 그대로 유지한 채 네 모서리만 위경도로 변환해 사각형 범위로 근사 표시합니다. 좌표계가 정북 기준으로 크게 회전되어 있지 않은 일반적인 경우에는 문제없지만, 회전이 큰 좌표계에서는 약간의 왜곡이 있을 수 있습니다. 업로드 이미지는 브라우저 메모리 문제를 피하기 위해 긴 변 기준 2000px로 축소되어 표시됩니다.
- **3차원 역산**은 실험적 기능입니다:
  - 관측점을 원시 포인트가 아니라 기존 그리딩 수준(격자 크기 기준 최대 3,000점)으로 축소하고, 메쉬도 활성 셀 기준 최대 70,000개로 제한합니다 - 더 상세하게(격자를 촘촘히, 레이어를 많이) 설정할수록 정규방정식을 여러 번 푸는 비용이 커져 실행 시간이 최대 1~2분까지 늘어날 수 있습니다. 매우 조밀한 역산은 지원하지 않으며, 상한을 넘으면 오류 메시지와 함께 거부됩니다.
  - 파라미터를 비워두면(기본값) 측선 간격과 자력이상 그리드의 방사평균 파워스펙트럼 기울기로부터 격자 크기·탐사 심도·레이어 수를 자동 산정합니다. 스펙트럼 심도 추정은 개별 이상체가 아니라 전체 자료의 "특징적인" 평균 심도를 근사하는 통계적 기법(Spector & Grant 1970)이라, 심도가 서로 크게 다른 이상체들이 섞여 있으면 자동값이 최적이 아닐 수 있습니다 - 자동 설정을 끄고 직접 조정하세요.
  - DEM 없이 GPS로 추정한 지형은 등고비행 가정(일정 AGL) 하의 **상대적** 굴곡만 정확하며, 절대 고도 기준은 사용자가 입력한 AGL 값에 의존하는 근사치입니다.
  - UBC 스타일의 자동 베타 쿨링(discrepancy principle) 없이 고정 반복 횟수 + 사용자 조정 "정규화 강도" 배수로 단순화했습니다. 사전정보가 없는 역산 특성상 해가 유일하지 않으며(non-unique), 특히 근지표에 국소적으로 강한 이상이 있는 실제 자료에서는 일부 셀의 자화율이 물리적 상한(SI 1.0, 안전장치용 상한일 뿐 결과를 임의로 제한하지 않습니다)까지 올라갈 수 있습니다 - 이 경우 정규화 강도를 높이거나 표시 임계값을 조정해 확인하세요.
  - 유도자화(induced magnetization)만 가정하며 잔류자화(remanence)는 고려하지 않습니다 - 이 역시 사전정보 없는 역산에서 흔히 쓰이는 표준적 단순화입니다.
  - 자화율 자체의 절대값보다는 **상대적 위치·형태(어디에 이상대가 뭉쳐 있는지)**를 참고하는 용도에 적합합니다.
